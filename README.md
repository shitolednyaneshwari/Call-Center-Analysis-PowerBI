# Call Center Analysis Dashboard | Power BI
## 📊 Project Overview
This project is a Call Center Analysis Dashboard created using Microsoft Power BI.
The dashboard provides insights into call volume, call duration, customer channels, call reasons, response time, sentiment, and call performance.
## 🎯 Objectives
- Analyze total call volume
- Track call duration and call hours
- Analyze calls by channel
- Analyze calls by state
- Understand major call reasons
- Analyze customer sentiment
- Monitor response time
- Understand SLA performance
- Create interactive data visualizations
## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Data Visualization
## 📈 Key Dashboard Metrics
- Total Calls: 32.94K
- Call in Hours: 13.74K
- Call in Minutes: 824.22K
- Average Call Duration: 25.02
## 📊 Dashboard Features
- Day-wise Calls
- Calls by State
- Total Calls by Channel
- Total Calls by Reason
- Calls by Sentiment
- Customer Response Time
- SLA Analysis
- Interactive Channel and City Filters
- Detailed Call Data Table
## 🔍 Key Insights
- The dashboard provides an overview of overall call volume.
- Call performance can be analyzed across different channels.
- Billing Questions, Payments, and Service Outages are included as major call reasons.
- Customer sentiment can be compared across different categories.
- State-wise analysis helps understand the geographic distribution of calls.
- Response time and SLA status can be used to analyze customer service performance.
